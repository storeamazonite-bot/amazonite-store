Authenticator setup

One-time owner enrollment for Microsoft Authenticator. The server generates the TOTP secret only after the owner email and password are verified. Nothing is stored by this page.

Enrollment generated.

In Microsoft Authenticator choose + → Other account → Enter code manually, then use the secret below. After saving AMAZONITE_TOTP_SECRET in the deployment environment, sign in with the 6-digit code.

Important: this secret is the second factor. Do not put it in GitHub, frontend source, screenshots, or chat. Store it only as the server environment variable AMAZONITE_TOTP_SECRET.
