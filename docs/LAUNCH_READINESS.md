# Amazonite Store — Launch Readiness

## Current baseline
- [x] Consumer-facing affiliate-store positioning
- [x] Product-level affiliate link policy
- [x] Central product registry schema
- [x] Affiliate disclosure on homepage
- [x] Existing SEO basics: title, description, canonical, robots/sitemap files

## Before monetized launch
- [ ] Populate every live product with verified AliExpress affiliate URL
- [ ] Verify each URL resolves to the intended product
- [ ] Verify product availability for target markets
- [ ] Verify price and product facts from current authoritative data
- [ ] Confirm commission eligibility/rate from the affiliate portal where available
- [ ] Replace any demo/mock product claims with verified product data
- [ ] Test all CTA links on mobile and desktop
- [ ] Run broken-link and UX checks
- [ ] Review SEO/indexability and sitemap coverage
- [ ] Confirm legal/affiliate disclosure placement and wording

## Continuous operations
- [ ] Scheduled product/link health checks
- [ ] Stale-product detection
- [ ] New-product discovery pipeline
- [ ] Performance dashboard
- [ ] Automated alerts for failures
- [ ] Human approval gate for financial/legal/account changes

## Launch rule
Do not mark a product as monetized until its product-level affiliate URL and core product identity have been verified.
