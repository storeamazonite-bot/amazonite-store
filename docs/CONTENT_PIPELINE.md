# Amazonite Store — Content Pipeline

## Statuses
`idea -> research -> drafted -> reviewed -> published -> refresh -> retired`

## Required fields
- product_id
- target market/language
- search intent
- primary keyword/topic
- content type
- source evidence
- affiliate URL status
- disclosure status
- owner/reviewer
- publication date
- next refresh date

## Quality gate
A content asset cannot be marked `published` unless the linked product exists in the product registry, its affiliate URL is verified, factual claims have a source, and affiliate disclosure is present where required.

## Recommended asset types
- product page
- buying guide
- comparison
- FAQ
- short-form video script
- YouTube outline
- Pinterest pin copy
- social caption
