# Continuous Improvement Loop

Amazonite improves operationally through measured feedback rather than uncontrolled self-modification.

## Loop

**Observe → Diagnose → Hypothesize → Change → Test → Measure → Record → Decide**

### Triggers

- conversion regression
- broken or stale affiliate link
- failed automated test
- recurring production error
- SEO opportunity
- content underperformance
- new tool/provider with materially better capability
- workflow latency or reliability degradation

### Tool evaluation

When a new AI tool appears, Research evaluates capability, reliability, privacy/security, integration effort, and cost class. A tool is promoted only when it materially improves an existing capability or fills a real gap.

### Safe autonomy

Routine reversible changes may be automated when allowlisted and verified. High-impact, irreversible, financial, security-sensitive, or legal actions require human approval.

### Learning record

Successful and failed experiments are recorded as experiments or incidents so future agents can reuse the evidence instead of repeating avoidable mistakes.
