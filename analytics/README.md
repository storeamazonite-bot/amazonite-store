# Amazonite Store — Tracking & Analytics

## Status
Tracking is prepared in the repository but the store is **not launched** and no advertising campaign is active.

## Measurement plan
- Google Analytics 4: traffic, acquisition, engagement, outbound affiliate clicks.
- Microsoft Clarity: session recordings, heatmaps, rage/dead clicks, scroll depth.
- Affiliate click events: product ID, category, placement, CTA label, and outbound destination type.
- Core funnel: landing → product view → affiliate click.

## Event naming
- `product_view`
- `affiliate_click`
- `category_view`
- `search_used`
- `cta_click`

## Privacy
Do not collect names, emails, phone numbers, payment information, or other directly identifying information in analytics event parameters. Respect consent/privacy requirements before enabling analytics where required.

## Launch gate
Analytics configuration can be validated before launch. No paid marketing or public launch is authorized by this file; launch requires explicit owner approval.
